# Career Learnings Directory

A directory of contributor repos in the [second-hand-tigers](https://github.com/second-hand-tigers)
organization focused on career and non-technical professional development —
as distinct from the discipline-based project repos (like
[chem-eng-projects](https://github.com/second-hand-tigers/chem-eng-projects))
that focus on technical project execution.

## Why Two Kinds of Content

Project work and career development happen in parallel, not in sequence —
you're building a project *and* building a career at the same time, and
most people find themselves more pulled toward one than the other at any
given moment. That's expected, not a problem to fix.

The project repos and the career-learnings repos in this org are built to
be **complementary, not sequential**: start wherever you're actually
interested, get enough value out of it, and — when you're ready — the
other kind of content is right there.
